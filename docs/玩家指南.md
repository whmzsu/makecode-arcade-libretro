# MakeCode Arcade 核心 · 玩家安装与游玩指南（小白版）

这份指南是给**只想用 RetroArch 玩 MakeCode Arcade 游戏**的人看的，不碰代码、不编译。照着做就行。

---

## 〇、先搞清楚：这东西是什么、不是什么

**是什么**：一个 RetroArch「核心」（相当于游戏模拟器引擎）。装好它之后，RetroArch 就能把 MakeCode Arcade 的游戏当「卡带」一样加载运行。

**能玩什么**：只认 **`.pxt64`** 这种游戏文件（叫「卡带镜像」）。

**两个最容易踩的坑（务必先看）**：

1. **只支持 64 位**。如果你的设备/系统只有 32 位（很老的机器），这个核心装上去会黑屏，跑不起来。现在绝大多数掌机、手机、电脑都是 64 位，基本不用愁，但别往 32 位系统上硬塞。
2. **不认 `.png` 卡带**。你在网上看到的 MakeCode Arcade `.png` 图片里**只有游戏源码，不是能直接玩的文件**。要先把它「导出」成 `.pxt64` 才能玩（见第三节）。核心的文件浏览器里也只显示 `.pxt64`。

---

## 一、下载核心

去这个发布页下载对应你设备的版本：

> https://github.com/whmzsu/makecode-arcade-libretro/releases

找最新一条发布（目前是 **core-v0.3.9**），下面有一排压缩包，按平台选：

| 你的设备 | 下载这个 |
|---|---|
| Windows 电脑（64 位） | `makecode_arcade_windows-x64.zip` |
| Linux 电脑 / 掌机（x64） | `makecode_arcade_linux-x64.zip` |
| 安卓手机 / 安卓掌机（64 位） | `makecode_arcade_android-arm64.zip` |
| Lakka / LibreELEC 系统等（musl） | `makecode_arcade_lakka-arm64.zip` |

> 不知道自己要哪个？先在电脑上用 Windows 版或 Linux 版试水最省事。掌机玩家看系统说明；拿不准就选带 `arm64` 的。

**下载后先解压**。解压出来会有两个关键文件：

- `makecode_arcade_libretro.so`（Linux/安卓，也可能是 `.dll` 或 `.dylib`，看平台）
- `makecode_arcade_libretro.info`（核心的说明文件，建议一起放）

## 二、把核心装进 RetroArch

### 方法 A：手动放文件（最稳妥，推荐）

1. 打开 RetroArch。
2. 进 **设置 → 目录**，记下两样东西的真实路径：
   - **核心**（Cores / Core 目录）
   - **核心信息**（Core Info 目录）
   - 不同设备路径不一样，所以这里让你现场看，**别照抄网上的路径**。
3. 把解压出来的核心文件（上面那个 `.so` / `.dll`）放进**核心**目录。
4. 把那个 `.info` 文件放进**核心信息**目录。**不装 `.info` 核心照样能加载运行 `.pxt64`，但 RetroArch 的内容浏览器靠 `.info` 里的扩展名来识别文件——没它，先选核心再「载入内容」时浏览器里看不到 / 不会自动关联 `.pxt64`，核心名字也只显示成文件名；用「载入内容 → 先选文件 → 再手动指定核心」或命令行仍可以跑。装上最省事，建议装。**

### 方法 B：用「安装或恢复核心」

RetroArch 主菜单 → **在线更新 / 安装或恢复核心** → 文件浏览器里选中你解压出来的核心文件即可。

> 注意：这个浏览器**只列出当前平台的核心扩展名**（Windows 显示 `.dll`、Linux 显示 `.so`），**`.zip` 不会出现在列表里**，所以一定要先解压。而且它**不会**把 `.info` 一起带过去——`.info` 要按方法 A 单独放。

装好后，在 RetroArch 里应该能在核心列表里看到 **MakeCode Arcade (unofficial)**。

## 三、安卓设备专属步骤（手机 / 安卓掌机）

如果你在**安卓手机或安卓掌机**（如 G Cloud、Retroid 等）上玩，安装方式有几个坑，单独说清楚：

**1. 先解压，再用「安装或恢复核心」**

安卓上的 RetroArch，「安装或恢复核心」文件浏览器**只列 `.so` 文件**，**`.zip` 不会出现在列表里**，所以一定要先把下载的 zip 解压，得到里面的 `makecode_arcade_libretro.so`。

主菜单 → **在线更新 / 安装或恢复核心** → 选中解压出来的那个 `.so`，它就会被拷进 RetroArch 的核心目录。

**2. `.info` 文件要单独放**

上面那个浏览器**不会**把 `.info` 一起带过去。你需要手动把 `makecode_arcade_libretro.info` 放到 RetroArch 的**核心信息目录**：

- 打开 RetroArch → **设置 → 目录**，找到「核心信息」（也叫 `libretro_info_path`）。
- 用手机文件管理器把 `.info` 复制过去。（不装 `.info` 核心也能跑 `.pxt64`，但内容浏览器看不到 / 不会自动关联 `.pxt64`、核心名只显示成文件名，建议装。）

> **⚠️ 注意：默认信息目录在内部 data 目录，普通用户碰不到**
> RetroArch 的「核心信息」目录**默认指向 App 内部 data 目录**（类似 `Android/data/com.retroarch/...`）。安卓 11 起启用了分区存储，**普通文件管理器进不去这个目录**，你既看不到它、也 Copy 不进去——所以在「设置」里看到路径不等于你能在文件管理器里找到它。
> **解决办法**：到 RetroArch **设置 → 目录 → 核心信息**，把这个目录**改成一个你能访问的位置**（例如在内部存储根目录新建一个 `RetroArch/info` 文件夹并指向它），再把 `makecode_arcade_libretro.info` 放过去即可。
>
> **核心目录不要手动改路径**：核心（`.so`）请用上面的「安装或恢复核心」让程序自动装进它的私有目录——那个目录有执行权限，最稳妥。**不要**为了"好找"把核心目录也改到内部存储根目录之类的地方，那样可能被放到没有执行权限的位置，反而加载失败。一句话：**core 让程序装，info 自己放。**

**3. 核心目录必须留在 App 私有空间（最容易翻车的一点）**

安卓 10 以后，`/storage/emulated/0`（就是手机「内部存储」根目录）是 **noexec** 的——核心放那里 RetroArch **能识别、但加载必失败**。

所以：让 RetroArch 把核心装进它**自己的私有目录**（用上面的「安装或恢复核心」就是装到那），**不要**手动把 `.so` 丢到内部存储根目录再手动指定路径。想知道真实路径，就在「设置 → 目录 → 核心」里看。

**4. 加载游戏**

核心装好后，和电脑上一样：**加载内容 → 选 `.pxt64` 文件**即可（`.png` 依然不认，先按下一节转成 `.pxt64`）。

> 实测：安卓 arm64 版在多个真机上都能正常跑（Android 11、Android 16 均验证过）。如果加载后黑屏，先回头检查上面第 3 点——核心是不是被放到了 noexec 的内部存储根目录。

## 四、拿到能玩的游戏（`.pxt64` 卡带）

### 方式 1：官方编辑器直接导出（最简单，推荐）

MakeCode Arcade 有在线编辑器，自带导出功能，不用装任何东西：

1. 打开你的游戏工程（makecode.com 那种网页编辑器）。
2. 进 **About（关于）→ Experiments（实验功能）**，开启 **Experimental Hardware**。
3. 把硬件目标切到 **VM**。
4. 同一个 **Download（下载）** 按钮，现在直接产出 `.pxt64` 文件。

> 详细图文教程（中英双语，含常见问题）：
> - 中文：https://github.com/whmzsu/makecode-arcade-cartconv/blob/main/MakeCode%20Arcade%20%E5%A6%82%E4%BD%95%E5%AE%98%E6%96%B9%E5%AF%BC%E5%87%BApxt64/%E5%AE%98%E6%96%B9%E5%AF%BC%E5%87%BApxt64%E6%8C%87%E5%AF%BC.md
> - English：同上链接里的 `.en.md`

### 方式 2：批量转换已有的 `.png` 卡带

你手里有一堆 `.png` 游戏图片、想一次性转成 `.pxt64`？用这个独立工具（带免安装便携包）：

> https://github.com/whmzsu/makecode-arcade-cartconv

Windows 下载便携包解压，把 `.png` 拖到 `cartconv.exe` 上即可；非 Windows 用 `node cartconv.js 游戏.png`。

## 五、开玩

1. RetroArch 主菜单 → **加载内容（Load Content）**。
2. 找到你的 `.pxt64` 文件，选中它。
3. 第一次会问「用哪个核心」，选 **MakeCode Arcade (unofficial)**（可以勾选「记住」）。
4. 游戏就开始跑了。

**画面规格**：160×120 分辨率、60 帧/秒（掌机小屏上会自动放大，正常）。音频 44.1kHz。

### 按键（默认）

| 你的手柄/键盘 | 游戏里的功能 |
|---|---|
| A 键 | A（跳跃 / 确认） |
| B 键 | B（返回 / 取消） |
| 方向键 ↑↓←→ | 方向 |
| START | 游戏内菜单（部分游戏用） |
| SELECT | 重置当前游戏（重开一局） |

> **想改键？** 游戏运行时按 RetroArch 热键呼出**快速菜单 → 控制（Controls）** 就能重绑，比如把 A/B 对调、换个键当菜单。这个核心**没有「选项」页**（快速菜单里选项是空的），所有键位调整都在这一个地方搞定。

> 小提醒：RetroArch 自己还有一个「呼出快速菜单」的热键（默认可能也绑在 Start/Select 上）。如果按 Start 同时弹出了 RetroArch 菜单，去 **设置 → 输入 → 热键（Hotkeys）** 把 Menu Toggle 改绑或设为 none 即可。

## 六、常用操作

| 我想…… | 怎么做 |
|---|---|
| 快进 / 慢放 | 直接按 RetroArch 的快进键就行，核心自动加速/减速，**不需要任何设置**。 |
| 重开当前游戏 | 按 **SELECT**，或快速菜单里选「重启游戏」。画面和声音都会复位。 |
| 换一张卡带 | 主菜单「加载内容」选新的 `.pxt64`，旧游戏会自动干净退出。 |
| 暂停 | RetroArch 自带的暂停。 |

> **不支持即时存档（Savestate）/ 回放（Rewind）**。这是核心的有意设计——它只做官方模拟器同等的「基本功能」，不做快照存档。RetroArch 会自动把相关按钮禁用，不是你操作错了。

## 七、出问题了？看这里

| 现象 | 原因 / 解决办法 |
|---|---|
| **整个黑屏，啥也没有** | 多半是 **32 位系统/前端**，这个核心不支持。换 64 位环境。 |
| **文件浏览器里看不到我的游戏** | 你的文件是 `.png`，不是 `.pxt64`。按第三节导出/转换成 `.pxt64`。 |
| **加载后弹出 `VM error 1014`** | 这张卡带里有单个数据段超过 32000 字节，核心会**明确拒绝**而不是黑屏。这不是核心 bug，是卡带太大。换一份 VM 兼容的导出，或让作者把游戏里的大数组拆小。（以前这种卡带会默默黑屏，现在至少告诉你原因了。） |
| **画面顶部出现红底白字 `VM PANIC xxxx`** | 游戏自己崩了（多半是游戏代码 bug，比如把 undefined 当数组用）。按 SELECT 重开通常能恢复；核心不会把 RetroArch 带崩。 |
| **按 Start 同时弹出了 RetroArch 菜单** | 热键冲突，见上面「按键」里的提醒，去热键设置里改绑。 |
| **核心列表里看不到 MakeCode Arcade** | `.info` 没放对目录，或核心文件没放进核心目录。回头看第二节。 |

---

## 八、一句话总结

下载对应平台的 zip → 解压 → 把核心和 `.info` 放进 RetroArch 的对应目录 → 准备好 `.pxt64` 卡带 → 加载内容开玩。记住三件事：**64 位、`.pxt64`、改键去快速菜单的 Controls**。

祝玩得开心。
